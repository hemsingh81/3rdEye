3rdEye — Feature Prototype

One product, three audiences, one rule that never bends: nothing hidden from the person being monitored.

A rough map of what we're building, grouped by who it's for. Click a dashboard mockup below to see how each one actually looks and feels.

See the dashboards →
Family
Parental controls, child always informed
  • ✓ Screen time limits & bedtime — real lockout, not just a report
  • ✓ Web content filtering (category + custom blocklist)
  • ✓ App install approval
  • ✓ Location sharing + geofence alerts
  • ✓ Child's own "what my parent can see" screen
Phase 1 ships this tier first — Android + Windows.
Employer
Disclosed workforce visibility, never covert
  • ✓ App & site usage, categorized by admin
  • ✓ Active/idle time, productivity rollups
  • ✓ Optional screenshots — off by default, visible indicator
  • ✓ DLP-lite alerts (file moved to USB/cloud, metadata only)
  • ✗ No keylogging. No covert webcam/mic. Ever.
Phase 4 — bundled with metered billing going live.
Fleet / MDM
Device management & anti-theft, company-owned hardware
  • ✓ Zero-touch enrollment (DEP / Android Enterprise / Autopilot)
  • ✓ Remote lock, remote wipe, lost-mode
  • ✓ Compliance checks (OS version, encryption, passcode)
  • ✓ Asset inventory & fleet compliance dashboard
Phase 5 — last, most infrastructure-heavy, least differentiated.
Cross-cutting, true for all three
● Mandatory, non-hideable agent icon on every platform
● Consent screen on enroll & on any feature-flag change
● One license, one agent, one unified checkout
● Works offline — enforces & collects locally, syncs later
